# Memory Card Game
A simple interactive Memory Card Game built with Java and Java Swing. Test your memory by flipping cards, finding the matching shapes and completing the game with the least amount of moves as possible!

## Overview
The game consists of 12 cards in a 3x4 grid. Each card contains one of 3 shapes: circles, squares or triangles. Players must flip 2 cards at a time to find the 6 matching pairs.

The objective is to match all cards while minimizing the number of moves.

## Features
- Randomized Cards
- Move/Match Counter
- Card Flip Animation
- Reset Button

## Tech Stack
- Java
- Java Swing

## Getting Started 
1. Clone the Repository
```bash
git clone https://github.com/ronybuena-sudo/Memory-Card-Game.git
```
2. Navigate to the project directory
```bash
 Memory-Card-Game
```
3. Compile the Java files
```bash
javac MemoryGame.java CardPanel.java
```
4. Run the game
```bash
java MemoryGame
```
